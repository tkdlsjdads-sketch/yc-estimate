영창산업개발 철거 견적 자동계산기 - PWA 설치 안내

[중요]
이 앱은 HTTPS 웹주소에서 열어야 휴대폰에 '앱 설치'가 가능합니다.
압축파일을 휴대폰에서 그냥 열면 설치 버튼이 나타나지 않을 수 있습니다.

[GitHub Pages로 올리는 방법]
1. GitHub 로그인
2. 새 저장소(Repository) 만들기
   예: yc-estimate
3. 이 압축파일 안의 파일들을 저장소 최상위에 업로드
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - .nojekyll
4. GitHub 저장소 Settings → Pages
5. Build and deployment → Deploy from a branch
6. Branch: main / root 선택 후 Save
7. 1~3분 후 Pages 주소가 생성됨
   예: https://사용자이름.github.io/yc-estimate/

[안드로이드 설치]
1. 위 Pages 주소를 Chrome에서 열기
2. 화면의 '앱 설치' 버튼 또는 Chrome 메뉴(⋮) → '앱 설치' / '홈 화면에 추가'
3. 설치 후 바탕화면의 '영창견적' 아이콘으로 실행

[아이폰 설치]
1. Safari에서 Pages 주소 열기
2. 공유 버튼 → '홈 화면에 추가'
3. 추가 후 홈 화면에서 실행
